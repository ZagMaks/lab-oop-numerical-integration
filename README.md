# lab-oop-numerical-integration
Проект обраховує інтеграл функції на певних межах, різними методами, та видає значення і похибки.
Варіант 8: Обраховує інтеграл від 0 до 1 від функції cos x * exp(-x^2)
Інструкція з запуску:
    1. Завантажте два файли (integrators.py та main.py)
    2. В коді main.py замініть target_function на потрібну вам функцію
    3. В функції main() замініть межі та похибку
    4. Запустіть код main.py
