## Структура проєкту

- `integrators.py` — модуль з ієрархією класів чисельного інтегрування.
- `main.py` — головний файл запуску програми.

## Постановка задачі

∫cos(x)*exp(-x^2) a = 0, b = 1, eps = 0.00006

## Інструкція запуску

```bash
    1. Завантажте два файли (integrators.py та main.py)
    2. В коді main.py замініть target_function на потрібну вам функцію
    3. В функції main() замініть межі та похибку
    4. Запустіть код main.py
```
